# A/B 对决：novel-eval writer vs chinese-novelist-skill

> 日期：2026-10-25
> 对局规则：同一题材 seed（守村人民俗怪谈，《我们村的傻子开口那天，全村都在等谁死》的 topic 输入），两套系统各自产出前 6 章。
> **三层裁判**：①自家 eval 引擎（利益关联）；②Claude Code 盲评（`claude-blind-verdict.md`）；③Antigravity agy 盲评（`agy-blind-verdict.md`）。两次盲评独立抛硬币、独立匿名（本次均落位 甲=skill / 乙=writer，纯属随机）。

## ⚖️ 终审汇总：三位裁判，两票 skill 版胜，差距评级不一致

| 裁判 | skill 版 | writer 版 | 判定 |
|------|:---:|:---:|------|

### 两家盲评共识的 writer 版结构性缺陷（必须正视）

1. **调性撕裂/超自然无规则**（Claude："超自然承诺过重且无规则"；agy："世界观逻辑灾难级精神分裂"）——尸身自动写字、朱砂圈自动新增、闻烟即哑等设定没有规则契约，"现实刑侦"与"灵异法术"互相拆台
2. **人物薄、工具化**（Claude："主角与守村人没有建立情感关系"；agy："沈昭是人形线索投喂机、机械降神"）——钩子工程在推情节，但没人替人物说话
3. **主角策略降智**（agy 独有锐评）：乙版女主靠"下跪+现编规矩+赌运气"推动，甲版女主用现代法理（五保资格/章程/功德簿）精准博弈——同为悬疑女主，智斗层级差一档

### 两家盲评共识的 skill 版短板

- Claude：中段复读式抒情、黄历时间线硬伤（一轮改稿可修）
- agy：开篇调性偏沉，下沉市场瞬时吸睛效率弱于强刺激爽文

## 二、综合判词

**终审结论：skill 版（文学路线）胜，writer 版输在结构性短板而非手艺。** 自家 eval 的"平局"判定被两位独立裁判推翻——它没能力看见的，恰恰是自家产品的盲区：人物情感密度和世界观自洽。writer 版的节奏引擎是真实优势（Claude 判 +13），但两家盲评共同指出：**钩子工程推不动没有人物的船**。

值得注意：两位盲评裁判都不知道甲乙的技术来源，却分别独立点出乙稿"遇事不决靠死人显灵"的生成惯性——这指向 writer 引擎的 prompt 设计（灵异兑现桥段太顺手，成了万能解法），是比评分更值钱的诊断。

## 三、方法论启示（升级为双盲评背书版）

1. **quality-gate 必须加人物维度硬下限**：两家盲评人物分差 +18/+26，自家 eval 只看到 +4——八维评估的 map prompt 对"人物动作系统/零台词塑造"的识别力不足，需在评估维度定义中补"人物行为语言塑造"的判据
2. **超自然规则契约机制**（P1-2 升级）：蓝图层的灵异设定必须登记"立规→用规→兑现"三步，禁止"无前置的自动书写/显灵"——两家盲评共同判定这是乙稿最致命伤
3. **处境钩优先级**（P1-3）：Claude 认可的 +13 节奏优势要保住，但 agy 提醒"外部危机频繁易显廉价"——钩子要与人物代价绑定，不与物理危机堆叠
4. **主角智斗层级**（新增处方）：甲版女主的"现代法理博弈"对乙版"下跪赌规矩"是维度差——blueprint 的角色指令应要求主角用其职业知识（教师/入殓师/记者）解题，而非情绪反应解题
5. **自家 eval 校准**：市场维度与两位独立裁判的偏离（-10~-15 分量级）需要 golden 集校准实验
