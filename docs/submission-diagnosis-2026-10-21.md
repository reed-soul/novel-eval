# 投稿诊断：为什么过不了盐选/番茄，以及怎么改

日期：2026-10-21 ｜ 样本：41 部成品（3.4–4.8 万字 / 18 章）+ 173 份审计报告 + 10 份评估报告
方法：平台规格核实 + 跨书量化统计 + 原文逐章读 + 机器评语回溯
定位：**这份诊断只谈文本，不谈代码。** 目标是把"过稿"从撞运气变成可复现。

---

## 0. 裁决

**不是文笔问题，是三个契约没签：产品规格、因果工程、结局兑现。**

三句话：

1. **规格错配是必败项。** 3.4–4.8 万字 × 18 章 × 2600 字/章的"分章长篇骨架"，同时踩中盐选（最优 1–2.5 万字、第一人称、禁"第 X 章"）和番茄（短故事编辑器**不支持分章节**）的格式门槛。**这一条不改，内容再好也读不到。**
2. **因果工程有系统性缺陷，且被机器抓到了 803 次。** 173 份审计里 79.2% 的 P0 集中在三类：使能缺失（29.5%）、巧合驱动（26.2%）、因果断裂（23.5%）。这正是盐选"剧情逻辑经不起推敲"那句话的逐条对应物。
3. **结局没兑现承诺。** 8 部样本里，同时做到"罪名落地 + 情感收束"的只有 3 部，全部在 10 月下旬；9 月的 5 部里 4 部没有司法动作。而"制度修订/会议掌声/意象留白"这三种收尾，两家平台都不收。

**最关键的一条过程事实**：机器在 6/10 的样本里把「市场」判为最低维（72–80，红线 80），Web 端直接给了 `block`。流程却用"78–83 边界带 + 三局两胜"把它放行了。**所以失败不是没被预测，是预测被人工覆盖了。**

## 1. 证据：机器早就说了"不"

### 1.1 十份评估的分数结构高度一致

| 作品 | 总分 | 最低维 | 机器原话（摘录） |
|---|---|---|---|
| 锈带 | 82 A | 市场 75 | "技术细节可能提高阅读门槛""缺乏易于影视化改编的高概念场景" |
| 物业管家 | 84 A | 市场 78 | "象征性处理可能削弱部分读者的爽感期待" |
| 夜的命名术 | 85 A | 市场 80 | "复杂度对泛读者门槛偏高，可能影响前期留存率" |
| 归乡 | 81 A | 市场 68 | "五章之内缺乏强外部冲突和戏剧钩子，节奏偏慢热" |
| 森铁 | 82 A | 市场 72 | "罪罚不匹配直接削弱免费读者期待的正义爽感" |
| 森铁（二跑） | 84 A | 市场 74 | "结局仅降级退休、正义不彻底……与爽感期待相悖" |
| 第二十一万次 | 75 B | 节奏 62 | "极端重复的叙事内容极易导致中段拖沓和读者弃读" |

**分型**：文笔 / 结构 / 情感稳定在 **88–92**，市场 / 节奏稳定在 **62–80**。也就是说，**问题从来不在"写得像不像小说"，在"读者愿不愿意读下去、愿不愿意付费"。**

而投稿门卡的就是这两个维度——它一直在响。

### 1.2 审计的 803 条 P0，79.2% 是同一类病

| 类型 | 占比 | 典型原文 |
|---|---|---|
| 使能缺失 missing-enablement | 29.5% | "三年前排污台账复印件"来源缺失；"迁移被人提前按下"无前置 |
| 巧合驱动 coincidence-driven | 26.2% | "死而复生的人恰好拄拐站在门口促成停手"；"后墙露出粘了七年的纸，没人发现" |
| 因果断裂 causal-break | 23.5% | "回执在法院，最快二十分钟"——倒计时崩解 |
| 动机缺失 | 6.6% | 反派主动交出能控制对方儿子的对账单，等于递刀 |
| 罪罚不匹配 | 5.6% | "追诉期已过，追不回被改变的人生" |
| 事实矛盾 / 线索不公 / 时间线 | 8.5% | 礼簿"撕剩半本"与"全本一页未烧"并存 |

**这三类的共同点：不是句子问题，是"读者凭什么相信"的问题。** 使能缺失＝"他凭什么做得到"没交代；巧合驱动＝"为什么偏偏这时"靠运气；因果断裂＝"结果"和"原因"之间断了链。

而且同一份文本三次跑审计，P0 数是 3 / 4 / 7 ——**波动 2.3 倍**。所以"P0 归零"不能当通过标准，真正的标准应该是：**这三类问题在结构上不再产生**。

### 1.3 开篇：10 月已经改对了，9 月全错

| 时段 | 第一人称 | 首句类型 | 首段即有威胁 | 典型问题 |
|---|---|---|---|---|
| 9 月（5 部） | **0/5** | 场景描写 4、异常 1 | 3/5 | 先讲职业与履历，再给威胁（"完成了第一千次采样"） |
| 10 月（5 部） | **5/5** | 事件 4、场景 1 | **5/5** | 标题高概念，正文仍是文学场景（钩子错位） |

这是好消息：**转向第一人称这一步是对的，而且已经生效**（10 月市场分 84–91 vs 9 月 76–84）。坏消息是：**规格、结局、体例没跟着一起转。**

### 1.4 结局：只有 3/8 兑现

| 作品 | 罪名/刑罚落地 | 情感落点 | 续集钩 | 判定 |
|---|---|---|---|---|
| 以房养老 | ✗ 末章零追责 | ✓ | 无 | 不过 |
| 低保 | 留置，未判刑 | ✓ | 伪钩 | 弱 |
| 遗容 | 仅"改判他杀" | ✓ | **强钩** | 不过 |
| 棺材 | 取保候审 | ✓ | **强钩** | 不过 |
| 冥婚 | ✓ "判得最轻" | ✓ | **强钩（纸人睁眼）** | 半 |
| 空棺 | ✓ 数罪并罚 | ✓ | 无 | **过** |
| 遗像 | ✓ 数罪并罚 | ✓ | 弱钩 | **过** |
| 替病 | ✓ 三项罪名 | ✓ | 弱钩 | **过** |

**规律很清楚：10 月下旬那三部（空棺/遗像/替病）是唯一及格的形态。** 它们的共同点：具体人、具体罪名、数罪并罚、末句回到"人"而不是"制度"。

### 1.5 一个一眼毙稿的卫生问题

**41 部里 23 部正文残留「（本章完）/（全书完）/（第18章完）/（本幕终）」，共 114 处；其中 20 部的最后一句就是这四个字。**

```
（全书完）  （本章完）  （第18章完）  *（全书完）*  ## 全书完
```

对读者是小瑕疵，对编辑是**"流水线产物、未人工整理"的判定标记**。盐选明确禁止 AI 拼接内容，番茄 2026 年把「格式混乱」列为四大违规之一——这类残留会让编辑在读完之前就停下。

## 2. 平台规格：两份不同的尺，不能一稿通吃

| 特征 | 知乎盐选 | 番茄短故事 |
|---|---|---|
| 篇幅 | 8000 字起，**最优 1–2.5 万** | 6000 字起签；超短 8k–2.49 万 / 中短 2.5–8 万（3–5 万最受激励） |
| 人称 | **第一人称近乎必须**（TOP100 中 92% 一视角） | 一/三皆可，不减分 |
| 章节体例 | 阿拉伯数字 `1 2 3` 或 `【1】`，**禁"第 X 章"** | **编辑器不支持分章**，只能文内小标题 + 分割线 |
| 段落 | 30–80 字，≤3 行，对话独立成段 | 未分段是驳回项 |
| 节奏 | **每 800–1000 字一个反转/钩子** | 前 30% 是试读区；每小节至少一个钩子 |
| 结局 | 必须落地，"悬而不决易招骂" | 强反转 + 强情绪闭环 |
| 灵异/民俗 | 可写，但须"民俗外壳 + 人性内核"，纯恐怖受众窄 | **必须给现实解释**（人为/心理/梦境），否则按"封建迷信"驳回 |
| 批量产出 | "同类内容已多"可拒 | **明确打击**：5 月拒签 11.27 万本、7 月拒签 AI/水文 16 万本 |
| 独家 | 要求未发表 | 全部激励计划硬要求**独家原创首发** |

> 具体出处与不确定项见文末「证据边界」。标"官方"的引自 `fanqienovel.com/writer/zone/` 与知乎官方投稿手册；标"编辑经验"的来自二次源。

**三条必须立刻接受的推论：**

1. **一稿不能两投。** 两家都要求独家首发。必须先选一家，或者做两个不同版本、分开发布（且不能是同一故事的换皮——番茄的独家条款覆盖同题材同稿）。
2. **民俗怪谈线对番茄是红线边缘。** 10-22 之后的作品走"鬼是真的 + 人借鬼作恶"，这在盐选是加分（民俗外壳 + 人性内核），在番茄必须给现实解释。**同一条内容线，两家的通过逻辑相反。**
3. **"日产一部"本身在番茄是减分项。** 这不是质量问题，是账号风险问题。

## 3. 五个病因与改法

### 病因 A｜规格错配（必败项，最高优先）

**现状**：3.4–4.8 万字 / 18 章 / 2600 字每章 / `# 第N章`。
**编辑器怎么读**：盐选——"超出最优区 + 体例不合规"；番茄——"分章异常，格式违规"。

**改法**：把"一部小说"拆成两个明确的产品规格。

| | 盐选版（主推） | 番茄版（备选） |
|---|---|---|
| 字数 | **1.2–1.5 万字** | 2.5–3 万字 |
| 结构 | 单篇，`1 / 2 / 3` 分节，不出现"第 X 章" | 文内小标题 + 分割线，不分章 |
| 人称 | 第一人称 | 第一或第三 |
| 反转 | **12–18 个**（每 800–1000 字一个） | 每小节至少一个 |
| 灵异 | 可保留双层（鬼真 + 人作恶） | **必须落回现实解释** |
| 结局 | 具体人 + 具体罪名 + 情感落点 | 同上 + 更外放的爽感 |

**为什么主推盐选版**：1.2–1.5 万字正好是"一部单集中篇视频"的量（见 §6），一次生产三处用；番茄版要扩写 2 倍且要改灵异逻辑，成本更高。

### 病因 B｜因果工程缺陷（编辑说的"逻辑经不起推敲"）

**现状**：写完再打补丁（每部 16 处外科手术）。补丁能把"结果"补上，但读者读到的是"作者事后解释"。
**证据**：使能缺失 29.5% + 巧合 26.2% + 因果断裂 23.5%。

**改法：每个反转在写正文前，必须先填三行。**

```
反转 X（揭示于第 N 节）
① 使能：他凭什么做得到？——必须在揭示前 ≥1 处写到这个能力/工具/权限
② 触发：为什么是现在？——必须有一个"不得不动手"的时间压力事件
③ 公平：读者在哪一段见过这条线索，且当时误读了它？——给出具体段落号
```

三行缺一行，这个反转就不许进正文。**这是把"事后审计"改成"事前埋点"，也是长篇唯一能守住一致性的办法。**

### 病因 C｜结局不兑现（两家都扣分）

**三种错误收尾，逐一对照**：

| 收尾类型 | 实例 | 编辑怎么读 | 替换为 |
|---|---|---|---|
| 制度修复型 | "新规落地……台下响起第二阵掌声" | "这是结案汇报，不是小说" | 具体人被押走的具体场景 |
| 文学意象型 | 森铁："光斑落在'安'字上。安。绣完了的。" | "文学刊物稿，商业平台不收" | 一个具体动作 + 一句人话 |
| 续集钩型 | "纸人睁着眼，望着出山的路"（5/8 部） | "没写完"（盐选明说易招骂） | 删除，或改成已完结的余韵 |

**结局四件套模板**（空棺/遗像/替病已无意中做对，把它固化）：

```
1. 罪名点名：每个恶役至少一项具体罪名（不是"被带走"，是"故意杀人、诈骗、非法拘禁致人死亡"）
2. 刑罚落地：判几年 / 数罪并罚 / 谁判的（一句就够，不要写庭审）
3. 情感落点：回到一个具体的人与一个具体动作（"奶奶把爷爷旧棉袄的领口抻平"）
4. 末句：一句人话，不许是口号，不许是 PPT 金句（"都到家了" ✓ ／"报告会撒谎，轨迹不会" ✗）
```

### 病因 D｜开篇承诺与正文体验错位

**现状**：标题是知乎体高概念（《妹妹的冥婚：八字是假的，红棺是活的》），正文开篇却是文学场景慢起；9 月作品前 5 段讲职业履历。
**编辑怎么读**：标题承诺 A，正文给 B → "文不对题"。

**改法：前 300 字公式**（10 月下旬已部分做到，固化成硬约束）：

```
第 1 句：我在做什么具体的事（动作，不是心情）
第 2–4 句：一个不该出现的反常事实（越小越好，最好是一个物件）
第 5–6 句：这个反常跟我有什么关系（怕什么 / 会失去什么）
第 7 句起：我已经做了一件不该做的事（把主角推进坑里）
——前 300 字内不出现：单位名、职务说明、历史背景、家族谱系、专业流程
```

### 病因 E｜卫生问题（一眼毙稿）

**现状**：23/41 部残留（本章完）系脚手架，114 处。
**改法**：投稿前一条正则清空，并把"末句不得为标记行"写进导出脚本。这件事成本 10 秒，收益是"编辑不会在第一页判定为流水线产物"。

## 4. 改写示范

### 4.1 开篇：把"工作说明"改成"我的处境"

**原文（《危货假验》，80 分，市场 76）**

> 盛屿盯着屏幕，手里的二维码扫描枪悬在半空，第一次扫不出个所以然来。
> 季度自查第一天，宕州鸿运货运公司安全技术员盛屿照例扫描罐体检验报告。九十一份报告，八百公里外临垣市启衡检测出具，二维码、防伪码、鲜红印章——全部验真。
> 可他刚调完的卫星轨迹表就摊在另一个屏幕上：公司七十四部危货罐车，一月至四月，没有一部离开过本省。

前三段给了：一个动作、一个单位名、一个职务、一套流程、两个数字。**唯独没给"我怕什么"。**

**改写（同一情节，盐选体）**

> 我扫完第九十一份罐检报告，系统弹出一行绿字：该报告真实有效。
> 九十一份，全都是真的。二维码是真的，防伪码是真的，连那枚红章都是真的——八百公里外一家叫启衡的机构盖的。
> 可我们公司七十四辆危罐车，那四个月没有一辆出过省。
> 车没去过，章却盖回来了。
> 我叫盛屿，在这家公司做安全技术员，月薪七千二，房贷还有十九年。三年前我在质监系统递过一份材料，后来处分落在我档案里，写材料的人调走了——所以我学会一件事：数据没闭环，一个字都别吭声。
> 我把七十四辆车的全年轨迹导出来，一份一份对。
> 核到第三十一份，我停住了。
> 弘运〇三六，报告写着三月十七日上午九点二十，在临垣基地检罐，四十分钟。可那天九点到十点，这部车的定位钉在宕州西郊三号卸货位——它在卸三十吨液碱。门禁、过磅单、卸货确认单，三份记录齐全。
> 同一天，同一个小时，车在宕州卸货，报告在八百公里外盖章。
> 罐里装的是液碱、甲醇、液化气。一个没检过的罐，就是一粒上了膛的雷。
> 而我在十分钟前，已经把这三十一份报告的截图，发进了一个只有四个人的群。

改动只有四件事：①"我"在第一句就出现；②把单位/职务压成一句自我介绍，把**代价**（三年前的处分）挪到前面当利害；③把"他忽然明白断点在哪"这类解释删掉，改成**动作**（发进四个人的群）；④最后一句制造"我已经做错了事"的危机——这就是盐选的付费卡点位。

### 4.2 结局：把"结案汇报"改成"人"的落点

**原文（同书结尾）**

> 新规落地：授权委托书与检验码交叉验证机制写入危运监管条例……台下安静了一瞬，随即响起第二阵掌声。这一阵，比第一阵长。
> **报告会撒谎，轨迹不会。**

**改写**

> 贺连城是在会议室门口被带走的。两个便衣，一左一右，他没挣扎，只回头看了一眼投影上那行字，笑了一下。
> 判决书下来是三个月后：伪造证明文件、重大责任事故、行贿，数罪并罚，十二年。
> 老聂去看了他一次。回来跟我说，他在里头还在教人认章。"他说真的假不了。"
> 我没接话。
> 苏亮的车返厂重焊。水压试验合格那天，他在司机群里发了张检测单，配了六个字：贷款又贷了一笔。
> 我把师父那本手写检验记录要了过来，放在办公桌最下面那格。他没问我要干什么。
> 我留着它，是想以后每次有人跟我说"章是真的"，我能翻开给他看——真的章，是有人一笔一笔写下来的。
> 后来我又扫过很多份报告。每一次，系统都会弹那行绿字：该报告真实有效。

差别：**制度退到背景（一句"判了十二年"），人和动作顶到前面（看投影、教人认章、贷款又贷了一笔、手写记录）。** 末句不再喊口号，而是重复一个日常动作——这就是"情感落点"。

## 5. 兼顾油管：把三个产品对齐成一个

你说目标是"小说质量吸引观众 → 订阅/点赞/阅读"。这里有一个必须纠正的假设：

> **过稿 ≠ 质量好。** 盐选吃"代入感 + 情感"，番茄吃"爽 + 钩子密度"，两家都不测"观众愿不愿意看完 15 分钟"。过稿最多是**结构合格证**；真正的质量真值是**前 30 秒留存 + 完播率**。

而"单集短剧"这个目标，会把结构要求压得更狠：

| 载体 | 时长 | 需要的故事量 | 关键约束 |
|---|---|---|---|
| 单集短剧（真人/AI 剧） | 8–15 分钟 | **3000–5000 字脚本** | 3–5 个场景、人物 ≤6、对白驱动、一个主反转 |
| 单集解说/有声书 | 15–25 分钟 | **1.0–1.5 万字** | 一条主线、每 3–5 分钟一个爆点、物证可视化 |
| 多集有声书 | 2–4 小时 | 3–5 万字 | 章末钩子、人物弧光完整 |

**结论**：**1.2–1.5 万字的盐选版，正好是"单集中篇视频"的底本**。它同时是：
- 盐选投稿件（命中 1–2.5 万最优区）
- 油管单集解说脚本（15–20 分钟）
- 单集短剧的素材源（再压缩 1/3 成 4000 字脚本）

而现在的 4 万字 18 章版，只能做多集有声书——**这是三个目标里最费工、最难起量的那一个。**

所以建议把产线改成：

```
一个故事核（1 个反转 + 1 个物证 + 1 组人物）
   ├─ 主版 1.2–1.5 万字（第一人称 / 单篇 / 数字分节）→ 盐选投稿 + 单集中篇视频
   ├─ 短剧版 4000 字脚本（3–5 场景 / 对白驱动）→ 短剧
   └─ 扩写版 2.5–3 万字（加现实解释 / 文内小标题）→ 番茄（可选）
```

**这个改动同时解决了投稿和视频两个问题，是本次诊断里性价比最高的一条。**

## 6. 优先级

### P0｜本周就能做，成本以小时计

| | 动作 | 单位成本 | 收益 |
|---|---|---|---|
| 1 | **清脚手架**：删全部「（本章完）/（全书完）」及末句标记行 | 10 秒/部 | 消除"流水线产物"的第一印象 |
| 2 | **体例改造**：投稿版去 `# 第N章`，改 `1/2/3`；段落压到 ≤3 行 | 30 分钟/部 | 过格式关（否则内容读不到） |
| 3 | **结局四件套**：罪名点名 + 刑罚落地 + 情感落点 + 人话末句；删续集钩 | 1 小时/部 | 直接补上唯一"两家都卡"的维度 |
| 4 | **开篇 300 字重写**：按 §3-D 公式，动作开头、利害前置 | 1 小时/部 | 决定编辑是否读第二页 |
| 5 | **停止"边界带交付"**：market < 80 一律不投，先改再投 | 规则改动 | 机器报警 6 次被覆盖，这是根因 |

### P1｜本月

6. **盐选版重制**：从 4 万字里抽主线，砍到 1.2–1.5 万字，反转密度提到每 800–1000 字一个。这一步是"重写"不是"删减"——**删减会留下空洞，必须重搭节拍**。
7. **因果三问前置**：每个反转先填 ①使能 ②触发 ③公平线索，缺一不许写。
8. **反转密度表**：1.2 万字 = 12–18 个反转单位；一章 2600 字现在只装 2–3 个，是密度只有要求 1/3 的直接原因。

### P2｜稳定后

9. **双版本产线**：盐选版 + 番茄版（番茄版给灵异现实解释、改文内小标题）。
10. **投稿前外部红队**：用编辑 persona 独立读一遍。已有先例证明必要——《死人号》自建评估 87/A、盐选红线全过，两路外部红队一致判"大改后再看"（开篇 8.5 / 反转 4.0 / 爽感 3.0 / **规格 2.0**）。**自建门的"绿"不等于可投。**
11. **控制投稿节奏**：番茄对"日产多部"有明确治理，同一账号高频新建同质作品是账号风险。

## 9. 三个需要修正的假设

1. **"平台只是试金石" —— 只对一半。** 两家测的是不同东西：盐选测代入与情感，番茄测爽感与钩子密度。**过番茄不证明质量好，过盐选不证明能爆。** 真正的质量真值在油管的前 30 秒留存与完播率，那个数据现在还没有。
2. **"4 万字更适合单集视频" —— 反了。** 4 万字只能做多集；单集需要 1.0–1.5 万字。**把目标字数降到 1.2–1.5 万，是同时解决投稿与视频的唯一改动。**
3. **"AI 写得不够好" —— 不是。** 文笔/结构/情感长期 88–92 分，问题全在规格、因果、结局三处工程。**这三处都是流程问题，不是才华问题。**
