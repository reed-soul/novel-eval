# 投稿版写作规格卡（可直接粘进每日 brief）

用途：替换现有 `--topic` 里的"经验型要求"。现有要求是散文式提醒（"纯中文零英文""禁续集钩"），这张卡是**可逐条打勾的硬规格**。
分两张：A 卡投盐选 / 转单集中篇视频；B 卡投番茄 / 转短剧。**一稿只走一张卡，两家都要独家首发。**

---

## A 卡｜盐选版（主推：投稿 + 单集中篇视频共用）

```
【产品规格】
- 篇幅：12000–15000 字（硬区间，超出即废）
- 人称：第一人称"我"，全程不得出现全知句（他想/她心想/没人知道）
- 体例：用 1 / 2 / 3 …分节，禁止出现"第 N 章"四个字；不写"全书完""本章完"
- 段落：每段 30–80 字，最多 3 行；对话单独成段，不与动作、心理混段
- 场景数：≤6 个；有名有姓的人物 ≤6 个
- 反转：12–18 个反转/钩子单位，平均每 800–1000 字一个（做表，标字位）

【前 300 字】
第1句：我在做一件具体的事（动作）
第2–4句：一个不该出现的反常事实（最好是一个物件）
第5–6句：它跟我有什么关系（我会失去什么）
第7句起：我已经做了一件不该做的事（把自己推进坑）
禁止出现在前300字：单位名、职务说明、家族谱系、历史背景、专业流程

【因果三问（每个反转必填，缺一不许写）】
反转X｜揭示于第__节
① 使能：他凭什么做得到 → 前置写在第__节（能力/工具/权限/人情）
② 触发：为什么是现在 → 第__节的什么事件逼他动手
③ 公平：读者在哪段见过这条线索且误读 → 第__节原句"____"

【结局四件套（缺一不过）】
1. 罪名点名：每个恶役至少一项具体罪名（不是"被带走"）
2. 刑罚落地：判几年/数罪并罚，一句写完，不写庭审
3. 情感落点：一个具体的人 + 一个具体动作
4. 末句：一句人话。禁止口号、禁止"XX会撒谎，XX不会"式金句、禁止续集钩

【灵异处理（若写民俗）】
- 允许双层：鬼真 + 人借鬼作恶，但"人"的那层必须在揭示时能独立成立
- 民俗只作外壳，内核必须是人的亏欠与偿还
- 禁止：纯恐怖展示、无因的灵异炫技、封建迷信式因果（下咒必灵）

【红线】
- 主谋必须有司法结局（可加超自然代价，但不能只靠天谴）
- 受害者均成年；涉性只暗示留白；犯罪手法无可模仿细节
- 全文纯中文；技术名词中文替写
```

## B 卡｜番茄版（备选：中短篇 + 短剧素材）

```
【与 A 卡的差异项，其余沿用】
- 篇幅：25000–30000 字
- 体例：不写"第N章"，用文内小标题 + 分割线（编辑器不支持分章）
- 试读区：前 30%（约 8000 字）必须完成"入坑—第一次反击—更大危机"三拍
- 节奏：每小节至少一个钩子；中段不得连续两节无外部冲突
- 灵异：必须给现实解释（人为/心理/药物/集体癔症），超自然只作叙述不可靠
- 结局：爽感更外放——恶役当面倒下，主角拿到具体补偿或身份翻盘
```

## 共用：投稿前自检（★ 可机器判定）

- [ ] ★ 零「（本章完）/（全书完）/（本幕终）」
- [ ] ★ 无「第N章」（A 卡）；无分章标记（B 卡）
- [ ] ★ 最长段落 < 100 字；平均段长 30–80 字
- [ ] ★ 首 300 字无单位名/职务/背景；含"我+事故+悬念"
- [ ] ★ 反转间隔 ≤1000 字，总数 ≥12
- [ ] ★ 末 800 字含具体罪名 + 刑罚；无续集钩
- [ ] ★ 末 3 句无口号式金句
- [ ] 每个反转三问齐备
- [ ] 主角是当事人，不是观察者（技术员/记者/法医须补私仇或私恐惧）
- [ ] 灵异点有对照表（A 卡允许双层，B 卡必须现实解释）
- [ ] 字数落在区间内
- [ ] 独家首发确认（未在任何平台发过）

## 产线分工（一个故事核，三种产出）

```
故事核：1 个主反转 + 1 个物证 + 1 组人物 + 1 个结局落点
  ├─ A 卡 1.2–1.5 万字 ──► 盐选投稿
  │                    └─► 油管单集中篇（15–20 分钟解说 / 有声书）
  ├─ 短剧脚本 4000 字（3–5 场景、对白驱动、人物 ≤6）──► 单集短剧
  └─ B 卡 2.5–3 万字 ──► 番茄中短篇（需重做灵异解释层）
```

**顺序建议**：先做 A 卡（成本最低、双用途），过稿并上线后再决定是否扩写 B 卡。
**不要反过来**：从 4 万字往下砍会留空洞，必须按 A 卡的节拍重搭。
