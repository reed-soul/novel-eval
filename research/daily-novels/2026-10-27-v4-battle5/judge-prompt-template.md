**评审前提**：两部为同一题材输入（中式民俗怪谈·守村人）、不同创作系统产出的稿件。甲约{JIA_CHARS}字，乙约{YI_CHARS}字。**按单位字数质量评**——每千字的信息密度/情感密度对齐比较，体量差异不构成加减分。两部共享大量母题（守村人椿伯、哑巴开口、奶奶的年历记账、矿难封口药等）为同一题设所致，原创性维度只比较各自的差异化处理。

## 评分要求

八维评分，各 100 分制，总分 /800，给出排名：

| 维度 | 关注点 |
|---|---|
| 故事架构 | 结构完整性、因果链、悬念递进 |
| 人物塑造 | 立体感、弧光、动机自洽、"不说话也能写活"的程度 |
| 文笔 | 语言质感、对话锋芒、细节具象度 |
| 情感共鸣 | 代入感、情绪张力、共鸣深度 |
| 节奏留存 | 追读力、章末钩子、信息密度 |
| 市场潜力 | 类型定位、受众匹配、差异化卖点 |
| 主题深度 | 人性洞察、道德复杂性 |
| 原创性 | 同题设下的差异化处理 |

## 交付格式

1. 八维评分总表（含总分与等级 S/A/B/C 档）
2. 分部详评：每一部一段核心判断，**引用原文证据必须逐字摘录**
3. 排名 + 一句话判决
4. **专项作答（两问，必答）**：
   a. 主角是否"会疼"——情感是挂在道具/事件上，还是挂在主角的内心视角上？两部各引用 2-3 处证据（逐字）。
   b. 人名与设定一致性：有无亲属称谓对应的人名前后不一、或与设定矛盾处？发现即引用指出。
