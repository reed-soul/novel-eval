# 社会热点信源会诊（Cursor / 2026-09-28 实测）

**结论：丢掉「热搜≈选题」的假设。固定四源 = 正义网首页（案情主力）+ 警察网「大案要案」（警方通报）+ 百度热搜 JSON（热度校准）+ 豆包搜索后置求证。环球网社会、tophub、辟谣平台谣言曝光台均不适合当主源。**

## 推荐组合与抓取

UA 一律 `Mozilla/5.0 ... Chrome/122`。失败按箭头降级。

1. **正义网首页** `curl -L -A "$UA" https://www.jcrb.com/`  
   抽 `a[href*="livenews/2026"]`。今日样本：AI 套路贷催收裸照、代收货款电诈洗钱 16 人、拐卖外籍妇女二审、北汽原董事长受贿洗钱宣判（均为 20260928）。详情页 SSR，`p` 17–43 段。**主源。**
2. **中国警察网·大案要案** `curl -L -A "$UA" https://daan.cpd.com.cn/`  
   33 条里约半数为抓获/电诈/养老诈骗/命案积案。地方稿短但有骨架（沈北诈骗、五河拦二次电诈，正文 2–5 段，200）。**主源。**
3. **百度热搜 JSON** `curl -A "$UA" "https://top.baidu.com/api/board?platform=wise&tab=realtime"`  
   `success:true`，51 词。今日几乎全是亚运/时政，社会案以「广州地铁砍人系谣言」这种形态偶发。只做热度交集，不当案情池。备：`https://www.toutiao.com/hot-event/hot-board/?origin=toutiao_pc`（今日 50 条，同样娱乐向）。
4. **豆包搜索**（配额 500/月，日 1–3 次）  
   对 1+2 筛出的 3–5 个标题查「{标题} 警方通报」。未 source skill `.env` 时返回 0 条；配好后 260ms/3 条，含完整盗窃案骨架。

**兜底顺序：** piyao 首页（跳过 `/yybgt/`）→ 头条热榜 JSON → `https://www.chinanews.com.cn/society/` → 央视 JSONP 标题 `https://news.cctv.com/2019/07/gaiban/cmsdatainterface/page/society_1.jsonp?cb=society` → `https://newsnow.busiyi.world/api/s?id=weibo` → tophub → 环球网 `textarea.item-title`。

关键词过滤（应用于 1/2/兜底标题）：`通报|诈骗|电诈|宣判|刑拘|起诉|洗钱|拐卖|偷拍|辟谣|命案|绑架`。

## 现方案缺陷

1. **把热榜当原料。** 百度/头条今日 50 词几乎无案情骨架；热度只应用来决定「这条要不要做」，不能用来发现案子。
2. **环球网社会频道选错了职。** 能抓，但产品定位是奇闻+软文，不是法治。textarea 结构一改版就解析失败。
3. **piyao 子频道用错。** yybgt 是死档案；真正每日更新的是首页带 `20YYMMDD` 的辟谣/警方通报。
4. **tophub 被当成可靠备份，实测快照失效+偶发 SSL。**
5. **漏掉垂直法治源。** 正义网、警察网大案页今日案情密度远高于「社会频道」。
6. **豆包未当后置。** 拿它扫热词浪费配额；应用在已经过 1+2 过滤的标题上补通报原文。
