# 研究任务：悬疑小说每日选题的"社会热点信源"最佳方案会诊

## 背景
每天凌晨 2 点，一个无人值守的写作 agent 需要为一部中文悬疑小说选材。选题哲学：从近期真实热门社会新闻中找改编原料（"艺术从生活中来"）。最优质的原料 = 有案情骨架的事件：警方通报、法院判决、辟谣反转、新型犯罪。渠道是 YouTube 悬疑频道+番茄小说，题材需现实共鸣。

## 环境硬约束
- macOS 本机，可用工具：无登录无 JS 渲染的网页抓取（WebFetch）、curl、豆包搜索（火山引擎网页搜索 API，月配额 500 次，已验证可用）。
- 不能人工登录，无浏览器，无验证码处理。运行时刻凌晨 2 点，无人值守。
- 已实测：weibo.com/ajax/side/hotSearch 返回 403（微博官方热搜接口此路不通）。

## 当前方案（待你验证与挑战）
1. piyao.org.cn（中国互联网联合辟谣平台）直抓——辟谣/摆拍/警方通报类反转素材；
2. 环球网社会频道 society.huanqiu.com 直抓——每日社会新闻流；
3. 豆包搜索热词校准（已验证可用，能翻出热词聚合站与榜单转述）；
4. tophub.today 热榜聚合站——仅作备份。

## 你的任务
1. 实测验证上述 4 个源今天是否可无登录静态抓取，给出证据（命令+结果摘要）。
2. 寻找更优或补充信源，至少考察：澎湃新闻（热搜/社会频道）、央视网社会频道、公安部网安局/刑侦局公开传播页、人民法院报/中国裁判文书网、今日头条/抖音/百度热搜的公开接口或页面、RSSHub 公共实例、其它免登录聚合站。可自行扩展你认为更优的。
3. 每个候选按五维打分（各 1-5 分）：免登录可达性 / 社会新闻与法治含量 / 更新频率 / 反爬与改版稳定性 / 悬疑改编适配度（有案情骨架的事件密度）。
4. 给出最终推荐：2-4 个源的固定组合 + 每源具体抓取方式（URL/命令）+ 失败时的兜底顺序。
5. 明确指出当前方案的缺陷。
