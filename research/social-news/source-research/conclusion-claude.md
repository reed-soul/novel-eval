# 社会热点信源会诊·结论（Claude，2026-09-28 实测）

## 一、最终推荐（结论先行）

**固定三源 + 一校准**：

1. **正义网 www.jcrb.com**——案情骨架主力。`curl -sL -A "$UA" https://www.jcrb.com/` 解析首页 `<a>` 标题。实测 HTTP 200/169KB，当日（20260928）更新，案情类标题 39 条命中：「江西官方通报渣土车撞倒母女：司机被采取刑事强制措施」「代收货款成洗钱暗渠，16人落网」「拐卖外籍妇女案二审维持原判」——警方通报、法院判决、新型犯罪三类原料齐备。
2. **中国警察网 www.cpd.com.cn**——警方通报/典型案例。同法直抓，实测 200/309KB，案情 18 条命中（「江苏公安公布5起涉嫌新型黑恶违法犯罪典型案例」等）。
3. **热词层（双源互备 JSON）**：头条 `curl -s 'https://www.toutiao.com/hot-event/hot-board/?origin=toutiao_pc'`（实测 200/50 条）；百度 `curl -s 'https://top.baidu.com/api/board?platform=wise&tab=realtime'`（实测 200/51 词）。均免登录纯 JSON。

**校准**：豆包搜索只对入选热词做求证、找警方通报原文（实测 951ms/6 条/带权威标注），每日 3-5 次，500 次/月配额充裕。

**兜底顺序**：头条 JSON → 百度 JSON → 抖音 `https://www.iesdouyin.com/web/api/v2/hotsearch/billboard/word/`（实测 200/50 词）→ tophub.today 微博节点 `https://tophub.today/n/KqndgxeLl9`（SSR 可解析，实测 66 行真实标题，但慢：节点 94KB/2.3s、首页 1.27MB/5.6s）→ 豆包搜索兜底。

## 三、现有 4 源裁决

1. **piyao.org.cn**：可达（200/74KB 静态），但首页条目日期 0920/0918/0901——周级滞后，且以网信办治理动态为主；「权威辟谣」专区抽查竟为 2022-2024 存量。**降级为每周扫一次的反转素材库**，退出每日主力。
2. **society.huanqiu.com**：200 但仅 12.6KB、0 条文章服务端渲染（JS 壳页）；soc.huanqiu.com 直接 403。**从方案中删除**。
3. **豆包搜索**：实测可用，但被错放在发现环节（见下）。
4. **tophub.today**：SSR 可解析，保留为第 4 兜底；慢且改版风险高，不宜升级。

## 四、当前方案缺陷

1. 方案②环球网实际已失效：JS 壳页静态抓不到任何文章，等于每天空跑。
2. 全组合无高密度案情源：piyao 偏治理动态且滞后，热词榜无案情骨架——悬疑原料主力缺位，是最大结构问题。
3. 豆包搜索被当发现源：它是查询式工具，没有种子热词时只能盲搜，烧配额低产出；应后置为「求证+找通报原文」层。
4. 微博 403 后无 Plan B 的认知缺口：百度/头条/抖音第一方 JSON 已覆盖热词层，无需经 tophub 二手转述，更不必死磕微博。
5. 缺 JSON 优先原则：凌晨无人值守场景 HTML 解析最脆，应 JSON 接口做骨架、HTML（正义网/警察网）做案情补充，且每日记录各源 HTTP 码以便次日自动降级。
