> 2026-08-30。流程：三方初诊（zcode/cursor-grok/agy）→ v1 → 红队攻击（cursor-redteam）→ v2 → **双终审**（final-agy + final-cursor，均判"暂缓+阻断"，清单高度重合）→ 本版并入全部 6 项阻断的最小修法。
> 两终审评委预授权：阻断补齐即 ✅ 定稿，无需重审。战略层（§8.2 "已是最佳不必再议"清单）零改动。

## 0. 判决（四方收敛 + 红队修正 + 双终审补全）

**定位**：个人作者的「小说 IP 一源多形态创作台」——先让有声书这条线在书内完整成立（含第二本书从 Web 诞生且**第一屏就能用**），再谈多形态。不做协作 SaaS、不做时间线编辑器、不做 Work 抽象先行。

**v3 相对 v2 的变化**：v2 的战略全部保留；双终审抓出 6 处"意图定了但没写完整"的阻断（§4），全部按最小修法并入。两家评委共同认定以下为**已最佳、禁重开**：书为中心/顶栏两格/杀 v3/v4/杀七字段表单/不自动审听/试产 isDraft/M0 只许解禁性 CLI 补丁/M2 才抽象 DerivativeWork。

## 2. 「制作下一集」三态 CTA（v3 补全）

- **建线卡（冷启动，终审 P0 新增）**：书未登记时，有声书 tab 显示一张轻量建线卡——默认预设（引擎 volcengine、每集 3 章、无场景图时自动纯音频、产物路径 `dist/derivatives/<slug>/audiobook`），唯一主按钮 **[开启有声书并制作第 1 集]**，一键原子写入登记文件+建目录+拉起构建。不做多步向导。
- **新制作**：下一集=max+1、章节=未消费章顺延、预设来自登记文件；确认条含成本预估行
- **重制本集**：两个入口——「重制（复用缓存）」/「**强制重制（清缓存）**」（终审 P0 新增，解旅程③死锁）
- **补洞**：只重做缺的部分；同样提供清缓存选项
- 试产（--chars）仅高级入口；试产集 `isDraft` 不污染推断
- 制作完成不自动审听；给醒目「审听本集」按钮

## 3. 登记文件与配置分工（v3 消除双真相源矛盾）

`data/audiobook/registry.json`：
```json
{ "<bookId>": {
    "outRoot": "dist/derivatives/<slug>/audiobook",
    "scenesRoot": "…|null",
    "presets": { "engine":"volcengine", "chaptersPerEpisode":3, "skipVideo":true },
    "episodes": { "ep01": {"chapters":[1,3], "isDraft":false} }
} }
```

**分工铁律（终审裁定）**：registry = 管线拓扑/分集索引/制作预设；`projects/<书名>.json` = 发音表+音色班底（内容工程）。两者生命周期不同，**永不分合**——v2 中 M1"升级 projects/*.json 为唯一真相"的表述作废。
**集状态从文件派生**，派生公式（终审修正）：`skipVideo=true 时：有 mp3=就绪`；`skipVideo=false 时：有 mp4=就绪`；`有报告且无 P0=已审听`。无图纯音频不是"缺件"。

## 6. M0 验收标准（终版十条）

1. 顶栏两格；有声书/评估/审计非一级入口（旧路由重定向）
2. 书架→任意书→3 步内到达「制作第 N 集」，全程零键盘输入
3. 全站零处 v3/v4/制作版本/audiobook-v
4. 确认条人话+成本行
5. fix/srt 真实进 CLI；JobConsole 回调正确
6. **第二本书冷启动：有声书 tab 显示建线卡，一键开启并制作第 1 集**（全程 Web 内）
7. `--ep-start 10` 不抛错（CLI 与 Web 双侧）
8. 单集审听后其他集 QA 仍在
9. **无场景图的新书制作完成后，集卡显示中性「纯音频」，无红色报错**；有图书的"就绪"判定按 skipVideo 分支正确
10. **书 A 的集卡不出现书 B 的缩略图**；修改正文后「强制重制」能产出新音频（旅程③闭环）
